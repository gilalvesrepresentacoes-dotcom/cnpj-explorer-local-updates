# CNPJ Explorer Local — atualizações

Canal público autorizado para distribuir **somente o programa**. Nenhuma base de empresas, conta local, senha, credencial de e-mail ou configuração pessoal é publicada aqui.

## Como receber
Instale o pacote Windows completo fornecido no aplicativo/chat. A partir da versão 1.2.0, entre como administrador e use Ajuda > Verificar atualizações. O programa também verifica ao entrar e a cada 6 horas enquanto o administrador permanece conectado. A instalação exige confirmação e é impedida durante operações.

Os arquivos em distribution são pequenos pacotes para o atualizador, **não o executável inicial completo**. Não extraia esses arquivos sobre uma base de dados.

Cada Release identifica uma versão testada. O programa resolve a tag para um commit fixo antes de baixar o manifesto e o pacote. Alterações na branch não são instaladas automaticamente.

Integridade: origem HTTPS fixa, SHA-256, caminhos/tamanhos restritos e versões separadas da base. Não é uma assinatura comercial Windows. A atualização normal não substitui Electron/Python nem migra formatos incompatíveis de dados.

Validação: testes em Linux com dados fictícios e adaptadores do processo nativo. Execução e reinício em Windows real ainda dependem de confirmação; não confundir esses testes com execução do binário Windows.
